# User Guide

1. Run `python main.py`.
2. Option 1: enter a title to add a task. Empty titles are rejected.
3. Option 2: view all tasks. `[ ]` means pending and `[x]` means completed.
4. Option 3: enter a task ID to mark it completed.
5. Option 4: enter a task ID to delete it.
6. Option 5: exit.

Invalid IDs and non-numeric input show an error message and the program keeps running.
