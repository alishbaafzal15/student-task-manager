# student-task-manager

A Python console application to manage student tasks, built with Git and GitHub.

Project status: Testing

## Features
- Add tasks (empty titles are rejected)
- Display all tasks
- Mark tasks as completed
- Delete tasks by ID

## Setup
1. Install Python 3.8 or newer.
2. `git clone https://github.com/alishbaafzal15/student-task-manager.git`
3. `cd student-task-manager`

## Usage
Run `python main.py` and choose an option from the menu.

## Running Tests
`python -m unittest discover -s tests -v`
